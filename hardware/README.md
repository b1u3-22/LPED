# Hardware designs 
* Schematic, PCB design files and used 3D models used in the design for the die, charging dock and programming adapter
* The `complete_bom.csv` contains BOM with components selected from Mouser

## Structure
1. `lped`
    * Design files for the die
2. `lped_dock`
    * Design files for the charging station
3. `lped_prog`
    * Design files for the programming adapter
2. `3d_models`
    * 3D models used in PCB design files in all three boards
2. `complete_bom.csv`
    * BOM for all three boards, with components selected from Mouser
